Cadastrar cliente

Cadastra um cliente usando dados validados.

Authorizations:
bearerAuth
Request Body schema: application/json
required
nome
required
string [ 3 .. 150 ] characters
cpf
required
string^\d{3}\.\d{3}\.\d{3}-\d{2}$

A expressão valida o formato; os dígitos verificadores devem ser validados pela aplicação.

telefone
required
string [ 10 .. 15 ] characters
email
required
string <email> <= 254 characters
status
required
string (StatusCliente)
Enum: "ATIVO" "INATIVO"

Responses

Ambiente de desenvolvimento
