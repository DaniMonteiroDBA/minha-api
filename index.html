API de Gestão de Clientes (1.0)

Download OpenAPI specification:

API responsável pelo cadastro, consulta, atualização e remoção de clientes.

Esta API utiliza a metodologia API First: o contrato é definido antes da implementação do código.

Autenticação

Todos os endpoints exigem um token JWT válido enviado no cabeçalho:

Authorization: Bearer {token}

Autorização por escopos

Além de estar autenticado, o usuário deve possuir o escopo necessário para executar cada operação:

  • clientes.read: consultar clientes;
  • clientes.write: cadastrar ou atualizar clientes;
  • clientes.delete: remover clientes.

Mascaramento de dados

Os dados sensíveis devem ser mascarados antes de serem retornados:

  • nome: exibido integralmente;
  • CPF: exibido parcialmente;
  • telefone: exibido parcialmente;
  • e-mail: exibido parcialmente;
  • senha, token e credenciais: nunca devem ser retornados.

Cadastrar cliente

Cadastra um novo cliente.

Exige autenticação por token JWT e o escopo clientes.write.

O CPF deve possuir um formato válido e não pode estar cadastrado anteriormente.

Authorizations:
bearerAuth
Request Body schema: application/json
required

Dados necessários para o cadastro do cliente

nome
required
string [ 3 .. 150 ] characters

Nome completo do cliente

cpf
required
string^\d{3}\.\d{3}\.\d{3}-\d{2}$

CPF do cliente.

O formato deve ser validado pelo servidor. A expressão regular verifica apenas a estrutura do valor e não substitui a validação dos dígitos verificadores.

telefone
required
string [ 10 .. 15 ] characters

Telefone do cliente com DDD

email
required
string <email> <= 254 characters

Endereço de e-mail do cliente

status
required
string (StatusCliente)
Enum: "ATIVO" "INATIVO"

Situação atual do cliente
